# Areeba Editor (by Areeba Shaikh)

A photo and video editor that runs in the browser. No install needed.

## Features
- Photo and video editing with a home screen and bottom step bar
- Adjust: Brightness, Contrast, Saturation, Clarity, Sharpen, Temperature, Hue, Fade, Vignette, Grain, Blur, Light leak
- Auto adjust (analyses the current frame)
- About 60 filters in categories: Beauty, HD, Warm, Cool, Day, Night, Film, B&W, Creative, Pro
- Effects with live previews
- Background change for photos (manual brush)
- Trim, speed control and text for videos
- Export up to 8K (Pro, currently unlocked)
- Light and dark theme

## How to run
1. Open `index.html` in Chrome.
2. Tap "New video" or "Edit photo". The gallery opens automatically.

## Put it online (GitHub Pages)
1. Create a new GitHub repository, for example `areeba-editor`.
2. Upload `index.html` to it.
3. Go to Settings > Pages, choose the `main` branch, and save.
4. Open the link it gives you, for example `https://<your-name>.github.io/areeba-editor/`.

## Notes
- Pro is unlocked for testing. To lock it again, set `PRO_MODE = false` in `index.html`.
- Saved effects and the theme reset when the page is closed.
- Background change for video and automatic subject removal are not included.
- 8K and video sharpening need a strong phone.
